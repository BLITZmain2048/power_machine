# IEC Type 4A and PSS2B RMS implementation candidate

This is an engineering implementation candidate for balanced positive-sequence
RMS studies. **PowerFactory DLL parity has not been measured. Full conformity
with every standard diagram has not been established.** Do not use passing
synthetic tests as evidence of either claim.

The target editions are IEC 61400-27-1:2020, edition 2, and IEEE 421.5-2005.
The module docstrings identify their intended clauses and figures. Public
material available for this work included the IEC contents, parameter tables,
mode descriptions and the generator/rotation preview. A complete readable
copy of all control diagrams was not obtained. In particular the P/Q branches,
limiter corner cases and hybrid event semantics require a diagram-by-diagram
review before this candidate can be called a normative implementation.

## Available code

`power_machine.dynamics.iec61400` provides these independently callable blocks:

| Class | Intended IEC 2020 reference | Implemented behavior |
|---|---|---|
| GeneratorSetType4 | 7.4.4, Fig. 24 | Current lags and asymmetric rate bounds |
| ReferenceFrameRotation | 7.4.5, Fig. 25 | Rectangular voltage filter, direct high-voltage angle, low-voltage hold |
| PControl4A | 7.7.3, Fig. 32 | Reference/order lags, ramps, dip freeze, voltage scaling |
| QControl | 7.7.5, Fig. 34 | Q/U cascaded PI, open-loop modes, power factor modes, droop voltage, FRT and post-fault branches |
| CurrentLimitation | 7.7.6, Fig. 35 | Circular envelope, active/reactive priority, explicit voltage curves and high-voltage slope |
| QLimitation | 7.7.7–7.7.8, Figs. 36–37 | Constant bounds intersected with QP and QU tables |
| Protection | 7.8.1, Fig. 38 | Four duration relays with reset and latched trip |
| Measurement | 7.8.2, Fig. 39 | Independent U/I/P/Q/f first-order filters |

The common bounded lag implements `T dx/dt = clip(input)-x`, with rate
and state limits. Frozen positive-T blocks have zero derivative. Zero-T
measurement lags bypass the filter. A frozen zero-T Q order or steady voltage
returns the last accepted output. PI integration stops when saturation and
the derivative push in the same direction. Tables interpolate linearly and
hold their endpoints. Repeated or decreasing abscissas are rejected.

Q modes are 0 voltage, 1 reactive power, 2 open reactive power, 3 power factor
and 4 open power factor. The power factor input is `tan(phi)`. FRT modes 0,
1 and 2 select voltage contribution, pre-fault plus voltage contribution, and
pre-fault plus constant post-fault injection respectively. Mode 3 requires a
user-defined law and is rejected. `FFRT` is 0 normal, 1 fault, 2 post fault.
Both undervoltage and overvoltage trigger the fault branch. The steady
voltage and Q-order memories freeze during that branch.

`pss2b.PSS2B` realizes the IEEE 2005 Figure 8-2 dual-input structure with four
washouts, two input lags, the ramp-tracking transfer
`[(1+s*T8)/(1+s*T9)^M]^N`, three lead-lags, gain and output clipping.
Its first input is speed deviation, its second is generated electrical power
on machine MVA base. A zero washout time bypasses that washout. Integer orders
M=0..5 and N=0..4 are accepted when the resulting transfer is proper.
Zero-denominator lead blocks with a nonzero numerator time are rejected.
The first input selector and input clipping used by particular PF libraries
are not inferred. Positive output adds to the AVR voltage error.
If both input washout chains are bypassed, a nonzero DC output can be an
equilibrium. The connected exciter must include that output in its LF bias.

## Connection and initialization

```python
from power_machine.dynamics.converters import StaticGeneratorRMS
from power_machine.dynamics.iec61400 import QControl

port = StaticGeneratorRMS('wt', 'synthetic/wt', 'bus', 1, 100., 1,
                          s_base_mva=100., controlled=True)
wt = port.with_iec_type4a(q_control=QControl(MqG=2))
x0 = wt.init(1.+0j, 60.+5j)  # actual LF voltage, MW+jMvar
```

Pass `wt` as a device to `DAESolver` and `DynamicNetwork`. This wrapper owns
the controller/current states and uses the static generator equipment and
network bases. Register only the wrapper, otherwise injection is duplicated.
At every accepted step call `wt.accept_step(t,x,v)`. Honor `next_event_time`,
clear cached derivatives after discrete changes, and solve KCL again after a
trip. These are the existing runner's control-memory responsibilities. A raw
DAESolver call does not commit device memory. Threshold crossings are sampled
at accepted steps, so their timing has an O(h) uncertainty. No rejected Newton
evaluation changes FRT or protection memories.

`set_reference_frequency` supplies the measured frequency in per unit. A
network frequency observer must supply this for nonnominal studies. The
initial value 1 pu is explicit and is suitable for the nominal synthetic cases.
An undefined phase at zero voltage uses accepted PLL memory.

All current controls use equipment bases. Injected P and Q are positive.
The network current is `(ip - j*iq)*exp(j*theta)*S_equipment/S_network`.
Thus positive reactive generation uses a negative quadrature current.
`signals()` exposes `ipcmd`, `iqcmd`, `idref`, `iqref`, `pWT`, `qWT`, `uWT`,
`FFRT`, `CB_open` and complex `i_gs`. `iplimited` and `iqlimited` are clipped
commands. `ipmax`, `iqmax` and `iqmin` expose the candidate limiter bounds.
Their exact correspondence with exported frame ports still requires review.

Initialization solves controller biases from load-flow P+jQ. It preserves
the complex voltage and checks all continuous derivatives below 1e-8.
Infeasible Q/current limits or a load flow inside FRT are rejected.
Defaults are illustrative examples, not values from an operating plant.

## Remaining scope and limitations

- Diagram audit and exact standard switching semantics remain pending. The
  current FRT envelope uses instantaneous voltage for physical clipping and
  measured voltage for controller detection. Their interaction needs audit.
- Finite-rate P and current lags require positive time constants. Algebraic
  current generation and the standard standalone zero-T ramp realization
  have not been implemented. Unsupported settings raise errors.
- The exact effects of KPuFRT and the FRT PI branch routing need review.
  Current FRT commands follow the explicit Kqv injection law.
- The Type 3 generator alternative, Type 4B mechanics, plant controllers,
  harmonic/negative-sequence behavior and EMT dynamics are outside this work.
- The gamma electrical system is represented by external network elements and
  the trip current gate. No internal transformer/shunt gamma adapter is added.
- PF dPhimax, xWTref port bounds, PSS input selectors and PF array activation
  semantics are not implemented. Absent arrays are never reconstructed.
- Automatic frame binding, DLL identification and native-registry replacement
  are intentionally pending the exported signal connections. PSS2B exposes a
  control API and is tested against a synthetic synchronous machine. It is
  not automatically installed on imported synchronous-machine frames.

`iec_pf_parameters.json` is installed as package data. It contains 92 nominal
attribute correspondences with `confirmed` or `candidate` status. Confirmation
means nominal table correspondence only, not verified PF behavior. It contains
no instance values or exported object identities. Candidate entries must be
reviewed before any automatic importer uses them.

## Validation and references

`tests/test_iec61400.py` uses a two-bus network, an independent constant-PQ
load-flow fixed point, a current-source turbine and a Thevenin grid. It checks
five-mode equilibrium, bases and signs, a grid voltage step, a Q-reference
step, a 0.2 pu grid-source fault and recovery, saturation and step halving.
The voltage measurement bypass in the convergence scenarios aligns FRT with
the scheduled voltage event. Filtered detection is tested separately, without
a claim of exact crossing-time convergence. A direct 0.2 pu terminal test
checks the frozen derivatives and reactive injection sign.

`tests/test_pss2b.py` compares independent complex frequency responses for
several M/N combinations and tests an illustrative one-axis flux-decay SMIB
machine with AVR feedback and a mechanical-power step. It checks equilibrium,
output limits and step halving. These are synthetic numerical tests, not
validation against measured data or a vendor DLL.
